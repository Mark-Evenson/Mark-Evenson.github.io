# Mark Evenson Engineering Portfolio

Static portfolio prepared for GitHub Pages.

## Publish

1. Create a GitHub repository named exactly `<your-username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.

The repository root must contain `index.html`, `portfolio-content.js`, `.nojekyll`, and the `assets` folder. Do not upload the enclosing folder as another directory level.

## Edit portfolio wording later

Open `portfolio-content.js` in GitHub, select the pencil icon, edit only the text between the backticks, and commit the change. GitHub Pages will republish the site automatically.
